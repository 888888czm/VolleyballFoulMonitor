# 🏐 排球犯规自动监测与辅助记录系统 (Volleyball Foul Monitor)

这是一个基于 Python、OpenCV 和 PyQt5 开发的排球比赛犯规自动监测辅助工具。系统能够接入外部摄像头（或读取本地视频），实时分析画面，并在检测到疑似犯规（如触网、过中线）时自动报警、录制视频片段，并在结束后生成详细的 CSV/PDF 报告。

> ⚠️ **郑重声明**：本项目仅供**学习、训练复盘和技术交流**使用。系统输出的报警和报告**仅供辅助记录，不能替代人工裁判的最终判罚**。正式比赛请以国家体育总局颁布的最新排球竞赛规则及人工裁判判决为准。

## ✨ 核心功能

*   **实时画面监测**：支持默认摄像头、外接 USB 摄像头以及本地视频文件输入。
*   **自动犯规判定**：内置规则引擎，基于人体姿态（当前默认使用模拟数据，极易扩展接入真实 AI 模型）判断“触网”和“过中线”等疑似犯规。
*   **自动录像取证**：触发犯规报警时，自动保存犯规前 3 秒与后 3 秒的视频片段。
*   **定时监测**：可自定义监测时长，到时自动停止。
*   **一键生成报告**：支持将所有犯规事件（时间、队伍、犯规类型、原因）导出为 `.csv` 或 `.pdf` 格式。

## 🛠️ 技术架构

*   **界面框架**：PyQt5 (多线程 `QThread` 防止界面卡顿)
*   **计算机视觉**：OpenCV (视频流读取与画面录制)
*   **规则引擎**：基于坐标位置的几何判定（内置模拟数据，支持接入 YOLOv8-pose）
*   **数据报告**：Pandas (CSV 导出)、ReportLab (PDF 排版)

## 🚀 快速开始
##  方案一
### 1. 环境准备
请确保你的电脑已安装 Python 3.8+，然后在命令行执行以下命令安装依赖：
```bash
pip install numpy pandas opencv-python PyQt5 reportlab
```

### 2. 直接运行源码
```bash
python czm2208.py
```

### 3. 打包为独立 EXE 程序 (Windows)
由于本项目依赖了 PyQt5、OpenCV 等包含大量动态链接库的第三方库，普通的打包命令容易导致“找不到模块”或“闪退”。推荐使用以下命令打包（**请在 CMD 中执行**）：

```cmd
pyinstaller -y --onedir --console --clean --collect-all pandas --collect-all numpy --collect-all cv2 --collect-all PyQt5 --collect-all reportlab czm2208.py
```
*   `--onedir`：生成文件夹模式，启动速度比单文件快，且不易报错。
*   `--collect-all`：强制将底层库和 DLL 完整打包，避免 `ModuleNotFoundError`。
## 方案二
直接运行“排球犯规监测系统.exe”文件即可

## 📂 目录结构说明

**当前项目为极简的单文件结构：**

```text
├── czm2208.py           # 主程序（包含所有功能逻辑）
├── error_log.txt        # 运行异常时自动生成的排错日志
├── clips/               # (运行时自动生成) 存放犯规录像片段
└── reports/             # (运行时自动生成) 存放导出的 CSV 和 PDF 报告
```

*(注：如果你后续需要导出包含中文的 PDF，请在根目录手动新建 `fonts` 文件夹并放入 `simhei.ttf`；如果需要接入真实 AI 模型，请新建 `models` 文件夹并放入 `yolov8n-pose.pt`。程序会自动识别它们。)*

## 🐛 常见问题与排错 (Troubleshooting)

1. **点击“开始监测”或“录像”时闪退？**
   通常是因为打包后的 EXE 缺少 OpenCV 的视频编解码器。请去 Python 的 `Lib\site-packages\cv2\` 目录下，找到 `opencv_videoio_ffmpeg*.dll` 文件，复制到生成的 exe 同级目录下。
2. **PDF 导出中文乱码？**
   若系统找不到中文字体，会自动回退为英文显示，不会导致程序闪退。如需中文，请在项目根目录新建 `fonts` 文件夹并放入 `simhei.ttf`。
3. **摄像头无法打开？**
   请检查设备是否被其他软件（如腾讯会议、钉钉）占用。程序内提供了“0（默认摄像头）”与“1（外接 USB 摄像头）”的选项，如果均失败，请尝试重启电脑或在系统隐私设置中允许应用访问摄像头。
4. **打包时提示 `PermissionError: [WinError 5] 拒绝访问`？**
   请关闭正在运行的旧版 exe，或更换打包目录（避免在 C 盘系统目录下打包）。
